# Tutorials

Four tutorials that build one real thing: a **looper** for a Neural DSP Quad
Cortex, reached from your main presets and coming back to whichever one you
came from. It's the author's own setup, and the problem this app was built to
solve. [Why a state machine](../why-a-state-machine.md) explains why it's a
problem at all.

1. [A looper preset](1-a-looper-preset.md) — program a preset by hand, and a
   switch that goes to it and back.
2. [A second way in](2-a-second-way-in.md) — enter the looper from another
   preset, and let the map make the copy the Pacer needs.
3. [Changing the looper](3-changing-the-looper.md) — edit it once, and every
   copy follows.
4. [Letting an AI build it](4-letting-an-ai-build-it.md) — the same looper,
   programmed by an assistant, then finished on the map.

Each starts from the **factory defaults**, so you can follow along without a
Pacer. If you have different gear, use its CCs instead of the Quad Cortex's:
the steps are the same.

You'll want a [simulated MIDI output](../guide/the-simulator.md) pointed at
your gear if you have it — hearing the looper respond is the best check — but
the log shows everything that would be sent either way.
