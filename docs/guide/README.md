# Guide

How to get things done. Each page is short and links to the
[reference](../reference/) for the details.

**Start here**

- [The simulator](the-simulator.md) — play your configuration on screen and
  drive your real rig with it, no Pacer needed.
- [Editing a preset](editing-a-preset.md) — change what a switch does, try
  it, keep it.

**Programming**

- [Switches and steps](switches-and-steps.md) — steps, control modes, toggles,

- [MIDI sent when a preset loads](preset-midi-on-load.md) — setting up your

- [Saving and sending](saving-and-sending.md) — snapshots, and writing to

**Going further**

- [Why a state machine](../why-a-state-machine.md) and the
